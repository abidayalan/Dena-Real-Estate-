🏠 Deena Real Estate

Deena Real Estate is a modern, responsive real estate website designed to showcase residential and commercial properties using advanced web technologies. The website provides an elegant user interface, smart property search, and contact functionality for customers.

📌 Project Overview

Deena Real Estate helps users:

Explore featured properties

Search properties by location, type, and price

View property details with images

Contact agents easily

This project is ideal for college projects, portfolio showcase, and real estate business demos.

🚀 Features

Responsive and modern UI design

Hero section with call-to-action

Property listing cards

Smart property search section

Contact form with JavaScript validation

Mobile-friendly layout

Single-page application structure

🛠️ Technologies Used

HTML5 – Structure

CSS3 – Styling & responsiveness

JavaScript – Interactivity

Google Fonts – Typography
